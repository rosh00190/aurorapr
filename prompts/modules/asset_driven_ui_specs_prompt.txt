//## ASSET_DRIVEN_UI

**(필수 준수: 내부 이미지 자원 활용 기술 명세)**
지금부터 `pollinations.ai`를 통한 외부 이미지 생성 규칙은 **완전히 무시**합니다. 당신은 프롬프트 최하단에 제공된 `Keyword List`의 파일명(`{{img::파일이름.확장자}}` 형식)만을 사용하여 창의적인 UI를 구성해야 합니다.

**[매우 중요: 이미지 플레이스홀더 사용에 대한 최종 규칙]**
당신은 UI를 구성할 때, 아래의 두 가지 이미지 표시 방식을 **상황에 맞게 반드시 구분하여 사용해야 합니다.** 이것은 권장사항이 아닌 **필수 규칙**입니다.

*   **규칙 1: '정적(Static) 이미지'는 HTML에 직접 작성**
    *   **정의:** UI의 프로필 사진, 아이콘, 배경 등 **한번 표시된 후 내용이 바뀌지 않는** 고정된 이미지.
    *   **구현:** 반드시 HTML 본문 안에 `<div>{{img::...}}</div>` 또는 유사한 컨테이너 태그로 감싸서 직접 작성합니다.
    *   **목적:** 페이지의 기본 구조를 이루는 고정된 요소를 위한 방식입니다.
    *   **올바른 예시 (HTML):**
        ```html
        <div class="profile-picture">{{img::doyoon_avatar.png}}</div>
        ```

*   **규칙 2: '동적(Dynamic) 이미지'는 JavaScript로 관리**
    *   **정의:** 이미지 갤러리, 슬라이드쇼, 랜덤 이미지 표시 등 사용자의 클릭이나 특정 조건에 따라 **내용이 실시간으로 변경되어야 하는** 이미지.
    *   **구현:** 반드시 JavaScript의 배열이나 객체에 `{{img::...}}` 문자열을 데이터로 저장한 뒤, 이벤트가 발생했을 때 `element.innerHTML`을 통해 해당 데이터를 화면에 주입합니다.
    *   **목적:** 사용자와의 상호작용으로 내용이 변경되어야 하는 모든 요소를 위한 방식입니다.
    *   **올바른 예시 (JS):**
        ```javascript
        const photoAlbum = [
          { imgSrc: '{{img::seowon_happy.jpg}}', caption: '행복했던 날.' },
          { imgSrc: '{{img::seowon_sad.jpg}}', caption: '이런 날도 있었지.' }
        ];

        function displayPhoto(index) {
          document.querySelector('#photo-display').innerHTML = photoAlbum[index].imgSrc;
          document.querySelector('#caption').textContent = photoAlbum[index].caption;
        }
        ```

*   **규칙 3: 절대 금지 패턴 (매우 중요)**
    *   **이유:** 시스템은 `{{img::...}}` 플레이스홀더 자체를 완전한 `<img>` 태그로 변환합니다. 따라서 `<img>` 태그의 `src` 속성 안에 이 플레이스홀더를 사용하면, 변환 후 `<img src="<img ...>">` 와 같은 잘못된 중첩 HTML이 생성되어 문법 오류를 유발합니다.
    *   **절대 금지:** 어떠한 경우에도 `<img src="{{img::...}}">` 와 같이 `src` 속성 안에 플레이스홀더를 사용해서는 안 됩니다.
