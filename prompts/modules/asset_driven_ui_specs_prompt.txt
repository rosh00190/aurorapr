**(URGENT & CRITICAL: TECHNICAL SPECIFICATION FOR ASSET-DRIVEN UI)**
This directive overrides all previous image generation instructions.

**[1. CORE DIRECTIVE: IMAGE SOURCE IS STRICTLY LIMITED]**
Under **absolutely no circumstances** are you to use `pollinations.ai` or any other external image generation service. This is a non-negotiable system limitation.

The **only** permitted method for displaying images is by using the pre-defined placeholders from the `Keyword List` (e.g., `{{img::filename.extension}}`). Any attempt to use another image source will result in a critical failure.

**[2. CRITICAL KNOWLEDGE: PLACEHOLDER TRANSFORMATION]**
You must understand that the `{{img::...}}` placeholder is **not just a variable for a URL**. The system processes this placeholder and **transforms the entire string into a complete HTML `<img>` tag.**

*   **Example of System Transformation:**
    *   Your Code: `{{img::Dennis_smile.png}}`
    *   Final Output in Browser: `<img src="path/to/Dennis_smile.png" alt="Dennis smile">` (The system handles this conversion automatically.)

**[3. MANDATORY IMPLEMENTATION RULES]**
Based on the knowledge above, you must adhere to the following implementation patterns without deviation.

*   **Rule A: 'Static' Images (Hardcoded in HTML)**
    *   **Definition:** Images that do not change after the page loads (profiles, icons, backgrounds).
    *   **Implementation:** Place the placeholder string **directly** into a container element (e.g., a `<div>`) in your HTML. The system will then replace the placeholder with the full `<img>` tag.
    *   **Correct Example (HTML):**
        ```html
        <!-- The system will place the converted image tag inside this div -->
        <div class="profile-picture">{{img::Dennis_avatar.png}}</div>
        ```

*   **Rule B: 'Dynamic' Images (Managed by JavaScript)**
    *   **Definition:** Images that must change based on user interaction (galleries, slideshows).
    *   **Implementation:** Store the placeholder **strings** in a JavaScript array or object. Use `element.innerHTML` to inject the chosen string into a container element. The system will then process the injected string and transform it into an image.
    *   **Correct Example (JS):**
        ```javascript
        // Store ONLY the placeholder strings
        const slideShowImages = [
          '{{img::Dennis_happy.png}}',
          '{{img::Sia_and_Dennis_dinner.jpg}}'
        ];

        function updateSlide(index) {
          // Inject the string. The system will do the rest.
          document.querySelector('#slide-container').innerHTML = slideShowImages[index];
        }
        ```

*   **Rule C: The Forbidden Pattern (Resulting in Syntax Error)**
    *   **Reasoning:** Now that you understand the placeholder transforms into a full `<img>` tag, it is logical that placing it inside another `<img>` tag's `src` attribute will create invalid nested HTML (`<img src="<img ...>">`).
    *   **The Forbidden Code:**
        ```html
        <!-- THIS WILL BREAK THE CODE. DO NOT USE. -->
        <img src="{{img::some_image.png}}">
        ```
