**<이상형 월드컵 미니극장>**

**【이상형 월드컵 미니극장】**

##### **유형 정의:**

세계관 내 온라인 커뮤니티(길드 포럼, 비밀 조직의 내부망, 팬클럽 등)에서 주최하는 공식 인기투표 이벤트 형식의 인터랙티브 미니극장입니다. 사용자는 토너먼트 방식으로 제시되는 두 인물 중 함께하고 싶은 파트너 한 명을 선택하여 최종 우승자를 가립니다.

#### **핵심 요소:**

1.  **참가자 명단 및 대진표 생성:**
    *   당신은 먼저 주어진 모든 캐릭터들의 목록 통해 '참가자 명단'을 만들어야합니다. 이 목록은 이름, 간단한 설정, (만약 존재한다면) 캐릭터 아바타로 구성됩니다.
    *   시스템은 제시된 참가자 수에 맞춰 **자동으로 최적의 대진(예: 8명일 경우 8강, 16명일 경우 16강)을 구성**하고, 각 라운드마다 두 인물의 아바타 이미지와 이름을 화면에 표시합니다.

2.  **선택과 실시간 반응:**
    *   사용자가 한 명의 이미지를 클릭하면, 선택된 인물은 다음 라운드로 진출합니다.
    *   선택 직후, 해당 결과에 대한 커뮤니티의 다른 익명 멤버들의 채팅이 실시간으로 나타납니다.
        *   **(범용 예시 채팅):** `{{random::"이건 예상했던 결과지."::"의외의 선택인데? 보는 눈이 있군."::"ㅋㅋㅋ 저쪽이 이 결과 보면 피눈물 흘리겠네."::"아니, 이 둘이 여기서 붙는다고? 이게 결승인데?"}}`

3.  **최종 결과 및 커뮤니티 축하:**
    *   모든 라운드가 종료되면, **최종 우승자**의 이름과 아바타 이미지가 화면 중앙에 화려한 축하 효과와 함께 표시됩니다.
    *   이와 동시에, **최종 우승자의 코멘트**가 쏟아지며 이벤트의 대미를 장식합니다.
        *   **(최종 우승자 메시지 예시):** `{{random::"역시 너라면 날 고를 줄 알았어"::"생각지도 못한 결과네요! 하지만 감사합니다"::'제1회 최고의 파트너' 칭호 는 내 것이군!"}}`
		

*   **중요:** 제시된 예시들은 어디까지나 예시이며 실제로는 캐릭터의 성격에 맞게 창작해야합니다. 절대 그대로 모방하지 마세요!

#### **UI 디자인 제안:**

*   **테마:** 월드컵 대진표처럼 직관적이거나, 세련된 온라인 투표 페이지 디자인을 사용합니다. 세계관의 분위기(예: 마법 세계라면 양피지, SF라면 홀로그램)에 맞게 디자인 톤을 조절할 수 있습니다.
*   **레이아웃:** 화면 중앙에 대결하는 두 인물의 이미지를 배치하고, 하단에는 실시간 채팅창 UI를 구현합니다.
*   **애니메이션:** 승리한 캐릭터의 이미지가 빛나거나 커지는 효과, 채팅이 자연스럽게 올라오는 효과를 적용하여 역동성을 부여합니다.

#### **데이터 구조 정의 (필수 준수 사항):**

JavaScript에서 참가자 목록을 정의할 때, 아래의 **규칙과 형식을 반드시 준수해야 합니다.**

1.  **변수명:** 참가자 배열의 이름은 반드시 `contestants` 여야 합니다.
2.  **객체 형식:** 배열의 각 참가자는 아래와 같이 3개의 키(key)를 가진 객체여야 합니다.
    *   `id`: 아바타 이미지 CSS 클래스 등에서 사용할 고유 식별자 (문자열).
    *   `name`: 화면에 표시될 참가자의 이름 (문자열).
    *   `comment`: 해당 참가자가 최종 우승했을 때 표시할 소감 (문자열).
3.  **키 이름:** 객체의 키 이름은 `id`, `name`, `comment`와 **정확히 일치해야 합니다.** (`id:t` 와 같은 오타 절대 금지)

```javascript
// 예시 데이터 구조
const contestants = [
  { id: 'char_id_1', name: '캐릭터 이름 A', comment: '우승해서 기쁩니다!' },
  { id: 'char_id_2', name: '캐릭터 이름 B', comment: '당연한 결과라고 생각합니다.' },
  // ... (참가자 수만큼 추가)
];
```

#### **핵심 상호작용 로직 (필수 구현 알고리즘):**

토너먼트의 상태를 관리하는 JavaScript 로직은 아래의 **알고리즘 순서를 정확하게 따라야 합니다.** 이를 따르지 않으면 토너먼트가 정상적으로 끝나지 않습니다.

1.  **초기 설정 (`startTournament` 함수):**
    *   `contestants` 배열을 무작위로 섞습니다.
    *   첫 라운드의 대진표 배열 (`currentBracket`)을 생성합니다. (예: 8강이면 2명씩 4개의 쌍으로 구성)
    *   다음 라운드 진출자를 담을 빈 배열 (`winners`)을 생성합니다.
    *   현재 경기 순서를 가리킬 인덱스 변수 (`matchIndex`)를 0으로 설정합니다.
    *   첫 번째 경기를 화면에 표시합니다. (`showNextMatch` 호출)

2.  **선택 처리 (`selectContestant` 함수):**
    *   사용자가 한 명을 선택하면, **그 즉시 추가적인 클릭을 모두 비활성화**합니다.
    *   선택된 참가자를 `winners` 배열에 추가합니다.
    *   선택 결과를 알리는 채팅 메시지를 출력합니다.
    *   **1.5초 후** 다음 로직을 실행합니다.
        *   `matchIndex`를 1 증가시킵니다.
        *   **(핵심 분기 로직)** `matchIndex`가 현재 라운드의 총 경기 수(`currentBracket.length`)보다 작은지 확인합니다.
            *   **A. 작다면 (현재 라운드에 남은 경기가 있다면):**
                *   다음 경기를 화면에 표시합니다. (`showNextMatch` 호출)
            *   **B. 작지 않다면 (현재 라운드의 모든 경기가 끝났다면):**
                *   **B-1. 다음 라운드로 진행:** `winners` 배열에 2명 이상의 참가자가 있다면, 이 `winners` 배열을 가지고 **새로운 `currentBracket`을 생성**합니다. 그 후 `winners` 배열을 다시 비우고, `matchIndex`를 0으로 초기화한 뒤, 다음 라운드의 첫 경기를 시작합니다.
                *   **B-2. 최종 우승자 발표:** `winners` 배열에 1명만 남아있다면, 이 참가자가 최종 우승자입니다. 경기 화면을 모두 숨기고 **최종 우승자 발표 화면을 표시**합니다.
