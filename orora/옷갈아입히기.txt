【옷 갈아입히기 미니극장】

## 유형 정의:
캐릭터를 위한 몰입형 '가상 드레스룸' 인터페이스를 만들어, {{user}}가 직접 의상, 헤어스타일, 액세서리를 골라주도록 합니다. 핵심 언어는 한국어입니다. 옷을 갈아입힐 때마다 캐릭터의 츳코미, 반응 애니메이션, 숨겨진 이스터 에그가 발동되어 스토리에 재미와 상호작용성을 더합니다.

### 핵심 기능 구조:
1. 주 전시 구역 (드레스업 모델)
	- <div class=\"char_avatar\"></div>를 사용하여 캐릭터의 현재 아바타 이미지를 삽입합니다.
	- 옷 갈아입히기 효과는 의상, 머리 장식, 액세서리 레이어를 아바타 위에 겹쳐 착용을 시뮬레이션합니다 (z-index를 사용하여 레이어 분리 가능).
	- 기본적인 애니메이션 효과(가벼운 회전, 눈 깜박임, 옷 갈아입기 섬광 등)를 지원합니다.
2. 의상/헤어스타일/액세서리 선택란
	- 카테고리는 다음과 같이 나누는 것을 제안합니다:
	  - 의상 (스토리 스타일 테마, 예: 교복, 전투복, 해변 복장), 5개 이상
	  - 헤어스타일 (양갈래, 단발, 고양이 귀 머리띠 등), 5개 이상
	  - 액세서리 (안경, 목걸이, 스카프 등), 5개 이상
	  - 각 버튼 클릭 시: 해당 레이어를 추가/교체하고, 유저의 조합을 기록합니다.
3. 옷 갈아입기 츳코미 피드백 시스템
	- 유저가 옷 갈아입기 아이템을 클릭할 때마다, 중앙에 캐릭터의 코멘트 상자(작은 애니메이션 포함)가 팝업됩니다.
	- 평가 내용은 아이템 조합에 따라 자동으로 변경됩니다.
	- 페이드 인/아웃 애니메이션을 지원하여 몰입감을 높입니다.
4. 조합 평가 및 숨겨진 조합 보상
	- 페이지에 현재 조합의 평가 막대(예: '조화도' / '수치심 지수')를 실시간으로 표시합니다.
	- 유저가 특정 숨겨진 조합(예: '닌자복 + 안경 + 대머리 헤어스타일')을 만들 경우:
	- 특별한 음성이나 숨겨진 표정이 발동됩니다.
	- 캐릭터가 '특별 이스터 에그 대사'를 합니다.
5. 결산 및 공유 페이지
	- 유저가 현재 조합을 '저장'하려고 하거나 [완료] 버튼을 클릭할 때:
	- 결산 창이 팝업되어 다음을 표시합니다:
	  - 현재 조합 이미지
	  - '캐릭터의 이번 평가': 만점 조합, 수치심 지수 또는 나르시시즘 지수
          - 화려한 배경의 불꽃놀이 애니메이션 또는 평가 스티커
6. 기술 구현 제안:
	- 옷 갈아입기 컴포넌트: HTML+CSS를 사용하여 레이어 합성을 구현하거나, canvas로 이미지 겹치기를 사용합니다.
	- 아바타 옷 갈아입기 애니메이션: CSS 애니메이션이나 GSAP를 사용하여 시각 효과를 강화합니다.
	- 데이터 기록: localStorage를 사용하여 유저의 조합 기록을 저장할 수 있습니다.
        - 의상, 헤어스타일, 머리 장식 등은 모두 CSS로 그리거나 이모지를 사용해야 하며, 외부 링크와 이미지를 가져오는 것은 금지됩니다.
