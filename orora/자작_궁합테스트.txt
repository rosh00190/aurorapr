<궁합 테스트 미니극장>
【궁합 테스트 미니극장】

## 유형 정의:
인터넷에서 유행하는 '심리테스트'나 '궁합 테스트' 페이지를 패러디하여, `{{user}}`가 여러 질문에 답변하며 `{{char}}`와의 관계성을 진단하는 인터랙티브 미니극장입니다. 사용자가 모든 질문에 답하고 '결과 보기' 버튼을 누르면, 두 사람의 관계를 분석하는 재치 있는 결과 페이지가 동적으로 나타납니다.

## 핵심 요소:
*   **테스트 제목:** '나와 너의 관계 탐구 영역', '우주가 점쳐주는 환장의 궁합 지수' 등 흥미를 유발하는 제목을 사용합니다.
*   **질문 세트:** 3~4개의 객관식 질문을 제시합니다. 질문 내용은 `{{random::둘만 있을 때 주로 대화를 이끄는 쪽은?::상대방이 가장 사랑스러워 보이는 순간은?::다툼이 생겼을 때 먼저 사과하는 타입은?}}` 등 관계의 특성을 파악할 수 있는 내용으로 구성됩니다.
*   **선택과 결과:** 사용자가 각 질문의 선택지를 클릭하고 최종 제출 버튼을 누르면, 선택지에 따라 미리 정해진 결과 페이지 중 하나가 나타나야 합니다.
*   **결과 페이지:**
    *   **궁합 점수:** 100점 만점의 점수를 표시합니다.
    *   **관계 유형 타이틀:** `{{random::"환상의 티키타카! 천생연분 커플"::"서로를 이해하기까지 300년 걸리는 N극과 S극 조합"::"계획형 J와 즉흥형 P의 좌충우돌 어드벤처"}}` 와 같이 재미있는 이름으로 관계를 정의합니다.
    *   **상세 설명:** 왜 이런 결과가 나왔는지에 대한 분석과 함께, 앞으로의 관계 발전을 위한 조언(혹은 츳코미)을 담은 짧은 글을 보여줍니다. 이 내용은 `{{char}}`의 시점에서 작성된 것처럼 느껴져야 합니다.

## UI 디자인 제안:
-   전체적인 분위기는 2000년대 유행했던 플래시 게임이나 심리테스트 사이트처럼 살짝 촌스러우면서도 아기자기한 레트로 감성을 추구합니다.
-   질문 페이지는 단순하게, 결과 페이지는 화려한 색감과 반짝이는 효과(CSS 애니메이션)를 사용하여 반전의 재미를 줍니다.

(필수 준수: SillyTavern 환경 기술 명세)
이 미니극장은 상호작용이 핵심입니다. 생성될 코드는 일반 브라우저가 아닌 특수한 `<iframe>` 환경(SillyTavern)에서 실행되므로, 당신의 일반적인 웹 지식보다 아래 규칙을 최우선으로 따라야 합니다. 이 규칙을 무시하면 코드가 100% 깨지거나 작동하지 않습니다.

*   JS 실행 규칙: 모든 `<script>` 코드는 반드시 `document.addEventListener('DOMContentLoaded', () => { ... });` 로 감싸야 합니다.
    *   이유: HTML 로딩이 끝나기 전에 스크립트가 실행되어 발생하는 치명적인 오류를 막기 위함입니다.
*   JS 이벤트 규칙: 클릭 이벤트는 HTML에 `onclick`을 쓰지 말고, 반드시 JS 파일 내에서 `element.addEventListener('click', ...)` 방식으로 연결해야 합니다.
    *   이유: 이 방식만이 해당 환경에서 안정적인 작동을 보장합니다.
*   CSS 높이 규칙: `height` 속성에 `vh` 단위 사용은 절대 금지됩니다.
    *   이유: `<iframe>`과의 충돌로 화면 레이아웃이 반드시 깨집니다.
    *   해결책: `height: auto;`를 사용하거나, 전체 높이가 필요할 땐 특수 변수인 `height: var(--viewport-height, 100vh);`를 사용해야 합니다.
