**<관계 연대기: 둘만의 업적 시스템 미니극장>**

#### **유형 정의:**
`{{user}}`와 `{{char}}`가 함께 만들어 온 역사를 게임의 '업적 시스템'처럼 보여주는 인터랙티브 미니극장입니다. 사용자는 카테고리별로 정리된 업적 목록을 통해 두 사람의 중요한 순간, 재미있었던 사건, 아직 달성하지 못한 과제들을 확인하며 관계를 되돌아보는 즐거움을 느낄 수 있습니다.

#### **핵심 요소:**
*   **게이미피케이션 UI:**
    *   **진행률 표시:** 화면 상단에 두 사람의 관계에 대한 전체 업적 달성률을 원형 또는 막대그래프로 시각적으로 표시해야 합니다. (예: `달성률 65% (13/20)`)
    *   **카테고리 필터:** 업적들은 `{{random::💕로맨스::😂코미디::😱드라마::🔍비밀}}` 등 4~5개의 카테고리로 분류되어야 합니다. 사용자는 탭 버튼을 클릭하여 원하는 카테고리의 업적만 필터링해서 볼 수 있어야 합니다.
*   **다양한 업적 콘텐츠:**
    *   **업적 카드:** 각 업적은 [아이콘, 등급, 제목, 설명, 달성 날짜]가 포함된 카드 형태로 표시됩니다.
    *   **상태 구분:**
        *   **달성 완료:** 카드는 밝은 색상으로 표시되며, 달성 날짜(`{{isodate}}` 형식 활용)가 명시됩니다.
        *   **미달성 (잠김):** 카드는 회색조로 처리되고, 아이콘은 자물쇠 모양, 설명은 `???`로 표시하여 호기심을 유발해야 합니다.
    *   **등급 시스템:** 모든 업적에는 중요도에 따라 `{{random::🥉브론즈::🥈실버::🥇골드::💎플래티넘::🎭히든}}` 등급이 부여되어야 하며, 등급별로 배지의 색상이나 디자인이 달라야 합니다.
    *   **업적 예시:**
        *   `[🥇골드] "서로의 마음을 확인한 날" - 처음으로 서로에게 고백했다. (달성: 2025-08-15)`
        *   `[🎭히든] "말할 수 없는 비밀" - ??? (조건 미공개)`
*   **상호작용:**
    *   사용자가 특정 '업적 카드'를 클릭하면, 해당 업적을 달성했을 당시의 상황에 대한 `{{char}}`의 짧은 회상이 담긴 상세 설명 팝업창이 나타나야 합니다.

#### **UI 디자인 제안:**
*   **테마:** PlayStation이나 Steam 같은 현대적인 게임 플랫폼의 UI를 참고하여, 어두운 배경에 생동감 있는 색상(등급별 색상, 진행률 바 등)을 포인트로 사용하는 디자인을 권장합니다.
*   **레이아웃:** 업적 카드는 화면 크기에 따라 2열 또는 3열 그리드 레이아웃으로 깔끔하게 정렬되어야 합니다.
*   **애니메이션:** 페이지 로딩 시 진행률 바가 0%부터 채워지는 애니메이션, 탭 전환 시 부드러운 페이드 효과, 카드에 마우스를 올렸을 때 살짝 위로 떠오르는 효과 등을 적용하여 역동적인 느낌을 주세요.

## INTERACTIVE_MODULE


### **SillyTavern 호환 팝업 모달 기술 가이드 (최우선 적용 규칙)**

이 모듈은 팝업 모달을 포함하며, **이 섹션의 규칙은 다른 모든 일반 CSS/JS 규칙보다 우선 적용됩니다.** SillyTavern의 특수한 `<iframe>` 렌더링 환경에서 모달이 **사용자의 실제 화면(Viewport) 중앙에 정확히 표시되도록** 하려면, 아래의 기술 규칙을 **절대적으로 준수**하여 모달을 구현해야 합니다.

#### **1. HTML 구조 원칙**

모달 관련 요소들은 미리 HTML에 정의되어야 합니다. 이해와 구현의 편의를 위해 **모달 관련 클릭 이벤트는 `onclick` 속성을 사용하는 것이 권장됩니다.**

*   **구조 예시:**
    ```html
    <!-- 모달을 위한 기본 HTML 구조 -->
    <div id="myModalOverlay" class="modal-overlay"></div>
    <div id="myModal" class="modal-content">
        <!-- 모달 내용이 여기에 들어갑니다 -->
        <h2>스킬 상세 설명</h2>
        <p id="modalDescription">스킬에 대한 자세한 설명...</p>
        <button onclick="closeModal()">닫기</button>
    </div>
    ```

#### **2. CSS 스타일링 원칙 (vh/vw 단위 절대 금지)**

**`vh` 또는 `vw` 단위는 절대로 사용해서는 안 됩니다.** 오버레이의 위치와 크기는 JavaScript로 동적으로 제어합니다.

*   **(오버레이) `position: absolute`:** 화면 전체를 덮는 배경도 모달 본문과 마찬가지로 `position: absolute`를 사용합니다. `top`, `left`, `width`, `height`는 모두 JS가 제어합니다.
    ```css
    .modal-overlay {
        display: none;
        position: absolute; /* JS로 위치/크기 제어 */
        background: rgba(0, 0, 0, 0.7);
        z-index: 20000;
    }
    ```

*   **(모달 본문) `position: absolute`:** 모달 창 역시 `position: absolute`를 사용하며, 위치는 JavaScript로 제어합니다.
    ```css
    .modal-content {
        display: none;
        position: absolute;
        z-index: 20001;
    }
    ```

#### **3. JavaScript 로직 핵심 원칙 (모든 위치/크기 동적 제어)**

JavaScript는 모달 본문의 위치뿐만 아니라, **오버레이의 위치와 크기까지 모두 동적으로 계산하고 설정**해야 합니다.

*   **원칙 1: 부모 창(Parent Window) 정보 활용**
    `window.parent.scrollY`, `window.parent.innerHeight`, `window.frameElement.getBoundingClientRect()` 등의 부모 창 정보를 적극 활용합니다.

*   **원칙 2: `onclick` 호출을 위한 전역 함수 할당**
    모든 스크립트는 `DOMContentLoaded`로 감싸되, 모달 제어 함수(`openModal`, `closeModal`)는 `onclick`에서 호출할 수 있도록 `window` 객체에 직접 할당해야 합니다.

*   **구현 코드 템플릿:** 아래 함수 구조를 반드시 준수하여 스크립트를 작성해야 합니다.
    ```javascript
    // DOMContentLoaded로 전체를 감싸 안정성 확보
    document.addEventListener('DOMContentLoaded', () => {
        const modal = document.getElementById('myModal');
        const overlay = document.getElementById('myModalOverlay');
        let isModalOpen = false;

        // 오버레이와 모달의 위치/크기를 모두 업데이트하는 핵심 함수
        function updateModalLayout() {
            if (!isModalOpen) return;

            // --- 부모 창 및 iframe 정보 가져오기 ---
            const parentScrollY = window.parent.scrollY;
            const parentScrollX = window.parent.scrollX;
            const parentViewportHeight = window.parent.innerHeight;
            const parentViewportWidth = window.parent.innerWidth;
            const iframeRect = window.frameElement.getBoundingClientRect();
            const iframeTopInDocument = parentScrollY + iframeRect.top;
            const iframeLeftInDocument = parentScrollX + iframeRect.left;

            // --- 오버레이 위치 및 크기 계산 (iframe 내부 기준) ---
            overlay.style.top = (parentScrollY - iframeTopInDocument) + 'px';
            overlay.style.left = (parentScrollX - iframeLeftInDocument) + 'px';
            overlay.style.width = parentViewportWidth + 'px';
            overlay.style.height = parentViewportHeight + 'px';
            
            // --- 모달 본문 위치 계산 (iframe 내부 기준) ---
            const modalHeight = modal.offsetHeight;
            const viewportCenterY = parentScrollY + (parentViewportHeight / 2);
            const modalTopInIframe = viewportCenterY - iframeTopInDocument - (modalHeight / 2);
            modal.style.top = modalTopInIframe + 'px';
            modal.style.left = '50%';
            modal.style.transform = 'translateX(-50%)';
        }

        // onclick에서 호출할 수 있도록 함수를 window 객체에 할당
        window.openModal = function() { // 인자는 필요에 따라 추가
            if (isModalOpen) return;
            isModalOpen = true;
            overlay.style.display = 'block';
            modal.style.display = 'block';
            
            updateModalLayout(); // 최초 레이아웃 설정

            window.parent.addEventListener('scroll', updateModalLayout);
            window.parent.addEventListener('resize', updateModalLayout);
            window.parent.document.body.style.overflow = 'hidden';
        }

        window.closeModal = function() {
            if (!isModalOpen) return;
            isModalOpen = false;
            overlay.style.display = 'none';
            modal.style.display = 'none';
            
            window.parent.removeEventListener('scroll', updateModalLayout);
            window.parent.removeEventListener('resize', updateModalLayout);
            window.parent.document.body.style.overflow = 'auto';
        }
    });
    ```
