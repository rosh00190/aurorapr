### <너만을 위한 `{{char}}`의 1:1 외국어 과외>

#### **유형 정의:**
`{{user}}`가 `{{char}}`의 모국어를 배우는 과정을 시뮬레이션하는, 유명 언어 학습 앱(듀오링고, 스픽 등)을 패러디한 인터랙티브 미니극장입니다. 이 미니극장의 핵심은, **학습에 사용되는 모든 단어와 예문이 두 사람의 실제 추억과 관계에서 비롯된 것**이라는 점입니다. 당신은 먼저 **학습 대상 언어**와 **UI 테마** 그리고 **난이도**를 무작위로 결정한 뒤, 그에 맞춰 `{{char}}`와 `{{user}}`의 관계를 기반으로 한 맞춤형 '커리큘럼'을 생성해야 합니다. 사용자가 모든 문제를 풀면, 최종 학습 성취도 리포트와 튜터가 된 `{{char}}`의 반응이 제공됩니다.

#### **핵심 요소:**

1.  **사전 설정 (무작위):**
    *   가장 먼저, **`{{char}}`의 모국어 또는 학습시킬 언어(`char_language`)**를 `{{char}}`의 설정에 기반하여 명확히 정의해야 합니다. (예: 영어,일본어,프랑스어,가상의 판타지 언어 등`)
    *   그다음, 아래 두 가지 핵심 설정을 무작위로 결정합니다.
        *   **UI 테마(예시):** `{{random::듀오링고 스타일::스픽 스타일}}`
        *   **학습 난이도:** `{{random::초급::중급::고급::마스터}}`

2.  **관계 기반 '커리큘럼' 생성:**
    *   퀴즈 내용은 `{{char}}`에 대한 지식 테스트가 아닌, **순수한 `char_language` 학습**이어야 합니다. 두 사람의 서사는 문제의 '예문'으로만 활용됩니다.
	
    *   **초급 (핵심 단어 암기):** 두 사람의 관계에서 중요한 '키워드'를 `char_language`로 배우는 객관식 문제.
        *   **(예시 - `char_language`: 일본어):** 한국어 단어 **'약속'**을 보여주고, `char_language` 선택지로 `[約束 (yakusoku), さよなら (sayonara), ありがとう (arigato)]` 중 올바른 것을 고르게 합니다.
    *   **중급 (문장 완성하기):** 두 사람의 추억이 담긴 문장의 빈칸에 들어갈 올바른 `char_language` 단어를 고르는 문제.
        *   **(예시 - `char_language`: 프랑스어):** "우리가 함께 봤던 ____을 기억해?" 라는 문맥과 함께 빈칸에 들어갈 **'바다(Mer)'**를 다른 프랑스어 단어들과 섞어 제시합니다.
    *   **고급 (문장 번역하기):** `{{char}}`가 `{{user}}`에게 할 법한 짧은 문장을 제시하고, 가장 자연스러운 `char_language` 번역을 고르게 합니다.
        *   **(예시 - `char_language`: 영어):** 한국어 문장 "**`{{user}}`, 보고 싶었어.**"를 보여주고, 정답 선택지인 `I missed you, {{user}}.` 와 미묘하게 틀린 오답 선택지(예: `I see you, {{user}}.`)들을 함께 제시합니다.
    *   **마스터 (뉘앙스 이해하기):** `char_language`의 관용어구나 문화적 뉘앙스가 담긴 표현의 의미를 추론하는 문제.
        *   **(예시 - `char_language`: 영어):** `{{char}}`가 "It was raining cats and dogs."라고 말하는 상황을 제시하고, 이 말의 진짜 의미가 '비가 억수같이 내렸다'임을 맞추게 합니다.

3.  **상호작용 로직:**
    *   한 번에 한 문제씩 출제되며, 사용자가 선택지를 클릭하면 즉시 정답/오답 여부를 피드백합니다.
    *   **정답 시:** 선택지가 초록색으로 변하며 긍정적인 사운드 효과나 메시지(예: "Perfect!")가 출력됩니다.
    *   **오답 시:** 선택지가 붉은색으로 변하며, 올바른 정답이 무엇이었는지 명확하게 표시해줍니다.
    *   스크립트는 사용자의 정답 개수를 정확하게 카운트하여 최종 점수를 계산해야 합니다.

4.  **최종 학습 리포트:**
    *   모든 문제를 푼 후, 최종 결과 화면이 나타납니다.
    *   **점수 및 등급:** 총 점수(예: 5/5점)와 함께 언어 구사 능력에 대한 재치 있는 등급을 부여합니다.
        *   **(등급 예시):** `{{random::[원어민 수준]::[보조개 번역가]::[파파고 절친]::[옹알이 단계]}}`
    *   **튜터 `{{char}}`의 코멘트:** `{{char}}`의 아바타와 함께, 결과에 대한 맞춤형 코멘트가 출력됩니다.
        *   **(만점 시):** "대단한데? 이 정도면 나랑 비밀 대화도 문제없겠어. 역시 내 학생이야."
        *   **(빵점 시):** "음... 특별 과외가 필요하겠네. 걱정 마, 내가 책임지고 가르쳐줄게."

## REQUIRES_IMAGE_AVATARS

#### **자주 있는 실수(오류방지)**

실행환경의 특수성을 고려해 안정적인 작동을 위해 아래의 최종 지침을 **반드시** 준수해야 합니다. 일반적인 웹 개발 지식보다 이 규칙을 최우선으로 적용하세요.*

1.  **HTML 구조는 '정적으로' 사전 정의할 것 (Mandatory Static HTML Structure):**
    *   **금지:** JavaScript의 `createElement`나 `innerHTML`을 사용하여 질문, 선택지, 피드백 요소를 **동적으로 생성하지 마세요.** 이 방식은 환경에 따라 불안정하게 작동할 수 있습니다.
    *   **권장:** **모든 질문 화면과 결과 화면은 처음부터 HTML 내에 각각의 `<div>`로 만들어두고,** 초기에는 CSS 클래스(예: `.hidden` 또는 `.active`의 부재)로 숨겨두어야 합니다. JavaScript의 역할은 이 요소들을 동적으로 만드는 것이 아니라, **미리 만들어진 요소들의 상태(클래스)를 제어하는 것**입니다.

2.  **화면 전환은 '명시적 사용자 액션'으로 구현할 것 (User Action-Based Transitions):**
    *   **금지:** `setTimeout`을 이용한 자동 화면 전환은 **SillyTavern 환경에서 실패할 확률이 매우 높으므로 절대 사용하지 마세요.**
    *   **필수:** **사용자가 직접 클릭하는 '다음 문제' 버튼을 반드시 구현해야 합니다.** 사용자가 답을 선택하면 모든 선택지를 비활성화하고, '다음 문제' 버튼을 표시하세요. 사용자가 이 버튼을 클릭했을 때만 다음 문제 화면을 보여주어야 합니다.

3.  **'다시 풀기' 기능은 '완벽한 상태 초기화'를 보장할 것 (Comprehensive State Reset):**
    *   '다시 풀기' 버튼에 연결된 함수는 **모든 UI 요소의 상태를 명확하게 초기 상태로 되돌려야 합니다.**
    *   이는 단순히 점수를 0으로 만드는 것을 넘어, **(1) 현재의 결과 화면을 완벽히 숨기고(`display: none`), (2) 가장 처음의 시작 화면을 다시 표시하며(`display: block`), (3) 모든 질문 화면과 버튼, 피드백 메시지 등의 상태(클래스, `disabled` 속성 등)를 첫 시작과 동일하게 초기화**하는 것을 포함해야 합니다.

4.  **`.hidden` 클래스는 `!important`로 선언할 것 (Mandatory `!important` for `.hidden`):**
    *   **문제점:** 다른 CSS 규칙과의 충돌로 인해 `.hidden` 클래스가 제대로 작동하지 않고 요소가 미리 보이는 오류가 자주 발생합니다.
    *   **필수 해결책:** `.hidden` 클래스를 정의할 때, **반드시 `!important` 키워드를 사용하여 최우선 순위를 부여해야 합니다.** 이는 다른 어떤 `display` 속성보다 우선하여 요소를 확실하게 숨겨줍니다.
    *   **정확한 코드 예시:**
        ```css
        .hidden {
            display: none !important;
        }
        ```
    *   **이 규칙을 반드시 준수하여, 의도치 않게 요소가 노출되는 오류를 원천적으로 방지하세요.**
