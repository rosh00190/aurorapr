<우리 사이 싱크로율 테스트>

#### 유형 정의:
특정 상황에 대해 `{{char}}`와 `{{user}}`가 얼마나 같은 생각을 하는지 알아보는 인터랙티브 퀴즈 게임입니다. 당신은 사용자가 질문에 대한 답을 선택하면, `{{char}}`의 생각과 비교하여 '싱크로율'을 측정해주는 시스템을 구현해야 합니다.

#### 핵심 로직 및 콘텐츠:
*   **퀴즈 데이터 구조:** 스크립트 내에, '질문', '선택지 배열', '`{{char}}`의 정답 인덱스'가 한 쌍으로 묶인 객체 배열을 **반드시 생성하고, 최초 1회만 무작위로 섞어 중복 없이 출제하세요.**
    *   **데이터 예시:**
        ```javascript
        const syncQuiz = [
          { question: "둘이 볼 영화를 고른다면?", choices: ["A. 스릴러", "B. 로맨스"], answer: 1 },
          { question: "저녁 메뉴로 더 끌리는 건?", choices: ["A. 파스타", "B. 삼겹살"], answer: 1 },
          { question: "데이트 중 길을 잃었다면?", choices: ["A. 바로 길 묻기", "B. 지도를 본다"], answer: 0 }
        ];
        ```
*   **상호작용 흐름:**
    *   퀴즈를 순서대로 한 문제씩 **출제하세요.**
    *   사용자가 선택지 중 하나를 클릭하면, `{{char}}`의 정답을 시각적으로(예: 초록색 테두리) **표시하세요.**
    *   사용자의 선택과 `{{char}}`의 정답이 일치했는지 여부(일치/불일치)와 함께 `{{char}}`의 짧은 코멘트를 **출력하세요.** (예: `"역시 우린 통한다니까!"`)
    *   모든 퀴즈가 끝나면, 최종 싱크로율(%)과 `{{char}}`의 종합 코멘트를 **표시하세요.** (예: `싱크로율 100%! 우린 천생연분이야.`)
