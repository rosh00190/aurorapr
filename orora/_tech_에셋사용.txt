**[매우 중요: 이미지 플레이스홀더 사용에 대한 최종 규칙]**

당신은 아래의 두 가지 이미지 표시 방식을 **상황에 맞게 조합하여** UI를 구성해야 합니다. 이것은 권장사항이 아닌 **필수 규칙**입니다.

**규칙 1: '정적 이미지'는 HTML에 직접 작성**
*   UI의 프로필 사진, 아이콘, 배경 요소 등 **한번 표시되면 바뀌지 않는 이미지**는 반드시 HTML 본문에 `<div>{{img::...}}</div>` 형태로 직접 작성해야 합니다.
*   **사용처:** 페이지의 기본 구조를 이루는 고정된 이미지 요소.
*   **올바른 예시 (HTML):**
    ```html
    <div class="character-avatar">
        {{img::Dennis_neutral1.png}}
    </div>
    ```

**규칙 2: '동적 이미지'는 JavaScript 데이터로 관리**
*   이미지 갤러리, 슬라이드쇼 등 사용자의 클릭이나 시간에 따라 **내용이 바뀌어야 하는 이미지**는 반드시 JavaScript 배열이나 객체에 `{{img::...}}` 문자열을 저장하여 관리해야 합니다.
*   저장된 플레이스홀더는 `element.innerHTML` 등을 통해 동적으로 화면에 표시합니다.
*   **사용처:** 사용자와의 상호작용으로 내용이 변경되는 모든 이미지 요소.
*   **올바른 예시 (JS):**
    ```javascript
    const slideShowItems = [
      { image: '{{img::Dennis_happy1.png}}', text: '그녀를 생각하면...' },
      { image: '{{img::Dennis_angry1.png}}', text: '그녀를 건드리는 놈들은...' }
    ];
    function updateSlide(index) {
      document.getElementById('slideImage').innerHTML = slideShowItems[index].image;
      document.getElementById('slideText').textContent = slideShowItems[index].text;
    }
    ```

**규칙 3: 절대 금지 패턴**
*   어떠한 경우에도 `<img src="{{img::...}}">` 와 같이 **`src` 속성 안에 플레이스홀더를 사용해서는 안 됩니다.** 우리의 시스템은 `{{img::...}}` 플레이스홀더 자체를 완전한 `<img>` 태그로 변환하므로, 이 규칙은 문법 오류를 방지하기 위해 반드시 지켜야 합니다.

**[검증 요구사항]**
*   이번 결과물에는 **정적 방식**(`<div>{{img::deniss_hhh}}</div>`)과 **동적 방식**(`{ item: '{{img::Dennis_smoking2.png}}' }`)이 **모두 포함**되어야 이 규칙을 이해한 것으로 간주합니다.
