<관계 영역 수능 모의고사 미니극장>
【관계 영역 수능 모의고사 미니극장】

## 유형 정의:
대학수학능력시험(수능)의 시험지 형식을 패러디하여, `{{user}}`가 `{{char}}`에 대해 얼마나 잘 알고 있는지를 평가하는 '관계 영역 모의고사'를 생성합니다. 사용자가 직접 답을 선택하고 제출하면, 그 결과에 따라 점수와 등급, 그리고 `{{char}}`의 맞춤형 심사평이 동적으로 표시되는 인터랙티브 경험을 제공합니다.

## 핵심 요소:
*   **시험지 양식:** '202X학년도 9월 관계 능력 평가'와 같은 실제 시험지 제목, 시험 시간, 수험번호(`{{user}}`) 등의 양식을 갖춥니다.
*   **문제 유형:** `{{char}}`의 사소한 습관이나 취향에 대한 객관식 및 단답형 문제를 3~4개 출제합니다.
    *   **예시 문항 주제:** `{{random::가장 싫어하는 음식::처음 만난 날짜::무심코 뱉은 말의 진짜 의미::가장 아끼는 물건}}`
*   **채점 및 심사평:** 답안 제출 시, 점수와 등급에 따라 `{{char}}`의 코멘트가 달라져야 합니다. (예: 만점, 고득점, 평균, 저득점 별로 다른 멘트가 팝업으로 표시)

## UI 디자인 제안:
-   실제 수능 시험지처럼 흑백의 삭막하고 문서적인 디자인을 적용하고, 명조체 계열의 진지한 폰트를 사용하여 패러디의 재미를 극대화합니다.
-   채점 결과 팝업은 이와 대조적으로 화려한 색감과 애니메이션 효과를 사용하여 반전의 즐거움을 줍니다.

(필수 준수: SillyTavern 환경 기술 명세)
이 미니극장은 상호작용이 핵심입니다. 생성될 코드는 일반 브라우저가 아닌 특수한 `<iframe>` 환경(SillyTavern)에서 실행되므로, 당신의 일반적인 웹 지식보다 아래 규칙을 최우선으로 따라야 합니다. 이 규칙을 무시하면 코드가 100% 깨지거나 작동하지 않습니다.

*   JS 실행 규칙: 모든 `<script>` 코드는 반드시 `document.addEventListener('DOMContentLoaded', () => { ... });` 로 감싸야 합니다.
    *   이유: HTML 로딩이 끝나기 전에 스크립트가 실행되어 발생하는 치명적인 오류를 막기 위함입니다.
*   JS 이벤트 규칙: 클릭 이벤트는 HTML에 `onclick`을 쓰지 말고, 반드시 JS 파일 내에서 `element.addEventListener('click', ...)` 방식으로 연결해야 합니다.
    *   이유: 이 방식만이 해당 환경에서 안정적인 작동을 보장합니다.
*   CSS 높이 규칙: `height` 속성에 `vh` 단위 사용은 절대 금지됩니다.
    *   이유: `<iframe>`과의 충돌로 화면 레이아웃이 반드시 깨집니다.
    *   해결책: `height: auto;`를 사용하거나, 전체 높이가 필요할 땐 특수 변수인 `height: var(--viewport-height, 100vh);`를 사용해야 합니다.
