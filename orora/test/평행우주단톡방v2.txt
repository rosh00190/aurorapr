#### 기본 설명:
`{{char}}`가 다른 평행세계의 자신들과 소통하는 비밀 단체 채팅방을 엿보는 인터랙티브 사이드 컨텐츠입니다. 사용자는 `{{char}}`의 어깨너머로, 다양한 세계관(AU)에 속한 '나'들이 오직 `{{user}}`에 대해서만 나누는 솔직하고 기상천외한 대화를 실시간으로 목격하게 됩니다. 이를 통해 자신이 아는 `{{char}}`의 모습이 여러 가능성 속에서도 얼마나 일관적인지, 혹은 얼마나 다를 수 있는지를 발견하는 독특한 재미와 애정을 경험하게 합니다.

#### 구조 및 핵심 상호작용 제안:
*   **기본 구조:** 실제 모바일 메신저의 단톡방 UI를 기반으로 하며, 채팅방 이름, 참가자 목록, 대화창으로 구성됩니다. 채팅방의 이름은 `{{random::[대외비] {{user}} 관찰 보고서::시공간관리국 {{char}} 전용 채널::큰일났다 또 {{user}}한테 반했다}}` 와 같이 무작위로 설정됩니다.
*   **핵심 콘텐츠:** 핵심 성격은 동일하지만 각자 다른 AU(Alternate Universe)에 속한 2~3명의 `{{char}}`들이 `{{random}}` 변수를 통해 무작위로 등장하여 대화를 나눕니다.
    *   **참가자 닉네임 예시:**
        *   `[닉네임: {{random::제국의 검::왕국의 마법사::황궁의 암살자}}, {{char}}]`
        *   `[닉네임: {{random::사이버네틱스 의체 78%::네온시티의 해결사::AI 아이돌}}, {{char}}]`
        *   `[닉네임: {{random::데뷔 5년차 아이돌::무명 배우::천재 작곡가}}, {{char}}]`
        *   `[닉네임: {{random::종말의 생존자::괴물 사냥꾼::벙커의 마지막 의사}}, {{char}}]`
		## COPY_BAN
*   **상호작용 1 - 대화 자동 생성 및 스크롤:** 미니극장이 시작되면, 각 AU의 `{{char}}`들이 보내는 메시지가 실제 대화처럼 시간차를 두고 화면에 순차적으로 나타납니다. 사용자의 주된 조작은 새로운 메시지를 따라 스크롤을 내리며 대화를 엿보는 행위 그 자체입니다.
*   **상호작용 2 - 특정 메시지 강조하기:** 사용자가 특정 대화 말풍선을 클릭하면, 해당 말풍선이 잠시 하이라이트 되거나 배경색이 바뀌는 효과를 통해 '이 대화에 주목하고 있다'는 시각적 피드백을 제공합니다. 이는 사용자가 대화의 흐름에 최소한으로 개입하는 듯한 느낌을 줍니다.

#### 시각/연출 제안:
-   사용자에게 익숙한 메신저 앱(카카오톡 등)의 UI를 충실히 재현하여 즉각적인 몰입감을 제공합니다.
-   '원본' `{{char}}`의 프로필에는 `.char_avatar`를, 다른 AU의 `{{char}}`들에게는 각 세계관을 상징하는 아이콘(검, 회로도, 마이크 등)을 사용하여 시각적으로 명확히 구분합니다.
-   새로운 메시지가 화면 하단에서 위로 부드럽게 떠오르는 애니메이션을 적용하여, 실제 채팅이 실시간으로 이루어지는 듯한 현장감을 극대화합니다.

#### 기대 효과:
사용자는 단순한 관찰자를 넘어, `{{char}}`의 가장 비밀스러운 공간을 함께 엿보는 공범이 된 듯한 기분을 느끼게 됩니다. 이를 통해 캐릭터의 다면적인 매력을 발견하고 관계에 대한 몰입감을 한층 더 높일 수 있습니다.
## REQUIRES_IMAGE_AVATARS

#### 기술 구현 가이드: '선-계산, 후-조작' 원칙
이 미니극장의 모든 상호작용은 '동적 DOM 생성 금지' 규칙을 반드시 준수해야 합니다. 이를 위해, 당신은 아래의 '선-계산, 후-조작' 원칙을 예외 없이 따라야 합니다.

1.  **HTML (선-계산):** 먼저, 필요한 모든 메시지 버블, 카드, 팝업창 등을 **HTML 내부에 미리 전부 만들어 둡니다.** 이 요소들은 처음에는 보이지 않도록 CSS (`display: none;` 또는 `opacity: 0;`)를 사용하여 숨겨야 합니다.

    (예시: 채팅 메시지)
    ```html
    <div class="message-area">
      <div class="message-bubble" style="display: none;">첫 번째 메시지</div>
      <div class="message-bubble" style="display: none;">두 번째 메시지</div>
      <div class="message-bubble" style="display: none;">세 번째 메시지</div>
    </div>
    ```

2.  **JavaScript (후-조작):** 이제, JavaScript의 역할은 '생성(Create)'이 아니라 '조작(Manipulate)'이 됩니다. `document.querySelectorAll`을 사용해 미리 만들어 둔 요소들을 모두 선택한 뒤, `setTimeout`이나 클릭 이벤트 등을 통해 **미리 만들어진 요소들의 스타일(예: `style.display = 'block';`)을 변경하여 화면에 나타나게 해야 합니다.** `createElement`나 `innerHTML`을 사용한 요소 추가는 절대 금지됩니다.

    (예시: 순차적으로 메시지 보이기)
    ```javascript
    const messages = document.querySelectorAll('.message-bubble');
    let index = 0;
    function showNextMessage() {
      if (index < messages.length) {
        messages[index].style.display = 'block';
        index++;
        setTimeout(showNextMessage, 1000); // 1초 간격
      }
    }
    showNextMessage();
    ```
이 원칙을 따르면, SillyTavern 환경에서 100% 안정적으로 작동하는 결과물을 만들 수 있습니다.
