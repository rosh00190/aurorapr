### **<평행우주 단톡방 엿보기>**

#### **유형 정의:**
어느 날, `{{char}}`가 다른 평행세계의 자기 자신들만 모여있는 비밀 단체 채팅방에 초대되는 상황을 연출하는 인터랙티브 사이드 컨텐츠입니다. 이 채팅방의 참가자들은 **모두 동일한 핵심 성격을 가졌지만, 각자 다른 세계관(AU)에 속해있습니다.** 유일한 대화 주제는 바로 각자의 세계에 있는 `{{user}}`에 대한 이야기이며, 사용자는 `{{char}}`의 시점으로 기상천외한 상황에 놓인 '나'들의 대화를 엿보는 독특한 경험을 하게 됩니다.

#### **핵심 요소:**
*   **실감 나는 메신저 인터페이스:**
    *   화면은 카카오톡이나 라인 같은 모바일 메신저의 단톡방 UI와 완벽하게 동일하게 구현해야 합니다.
    *   채팅방의 이름은 `{{random::[대외비] {{user}} 관찰 보고서::시공간관리국 {{char}} 전용 채널::큰일났다 또 {{user}}한테 반했다}}` 와 같이 재치 있게 설정됩니다.
*   **`{{random}}`으로 구현되는 다채로운 **AU(Alternate Universe)**의 '나'들:**
    *   성격 자체가 변하는 것이 아니라, 각기 다른 세계관에 속해있어 `{{user}}`와의 관계나 상황이 다른 2~3명의 `{{char}}`들이 등장합니다. 이들의 닉네임은 소속된 세계관을 암시해야 합니다.
    *   **참가자 예시:**
        *   `[닉네임: 제국의 검, {{char}}]` - 판타지 세계관의 기사
        *   `[닉네임: 사이버네틱스 의체 78%, {{char}}]` - 사이버펑크 세계관의 해결사
        *   `[닉네임: 데뷔 5년차 아이돌 {{char}}]` - 현대 연예계 세계관의 슈퍼스타
        *   `[닉네임: 종말의 생존자 {{char}}]` - 포스트 아포칼립스 세계관의 리더
        *   `[닉네임: 원본 {{char}}]` - 현재 사용자와 대화 중인 바로 그 `{{char}}`
*   **세계관을 반영한 동적 대화 내용:**
    *   한 명의 `{{char}}`가 `{{user}}`에 대한 질문을 던지면(예: `"다들 자기 세계 {{user}}는 오늘 뭐하고 있어?"`), 다른 세계의 `{{char}}`들이 자신의 세계관과 상황에 맞춰 대답하며 대화가 진행됩니다. `{{char}}`의 말투는 핵심 성격에 따라 일관성을 유지해야 합니다.
    *   **(대화 예시):**
        *   `[제국의 검]`: "내 {{user}}? 방금 드래곤의 습격으로부터 지켜주고 오는 길이다. 그분은 내가 없으면 안 된다니까."
        *   `[데뷔 5년차 아이돌]`: "난 방금 몰래 숙소 빠져나와서 잠깐 보고 왔어. 파파라치 때문에 10분밖에 못 봤지만."
        *   `[사이버네틱스 의체 78%]`: "내 {{user}}의 뉴럴 링크 상태는 방금 체크했는데, 안정적이더군. 오늘은 기분이 좋은 데이터가 감지됐어."
	## COPY_BAN
*   **상호작용 및 연출:**
    *   미니극장이 시작되면, 채팅 메시지들이 실제 대화처럼 0.5~1초 간격으로 순차적으로 화면에 나타나야 합니다. 사용자는 스크롤을 내리며 대화를 따라 읽게 됩니다.

#### **UI 디자인 제안:**
*   **테마:** 대중적인 메신저 앱의 디자인을 충실히 따릅니다. 사용자가 익숙함을 느낄 수 있도록 노란색과 갈색 톤의 채팅방 배경, 말풍선 디자인을 사용하세요.
*   **프로필:** '원본' `{{char}}`의 프로필 사진 위치에는 `.char_avatar`를 사용해야 합니다. 다른 AU의 `{{char}}`들은 각자의 세계관을 나타내는 간단한 심볼(예: 판타지-검 아이콘, 사이버펑크-회로도 아이콘)을 프로필 이미지로 사용하여 명확히 구분합니다.
*   **애니메이션:** 새로운 메시지가 나타날 때, 아래에서 위로 부드럽게 슬라이드 되며 등장하는 애니메이션을 적용하여 실제 채팅 같은 느낌을 극대화해야 합니다.

## REQUIRES_IMAGE_AVATARS


#### 기술 구현 가이드: '선-계산, 후-조작' 원칙
이 미니극장의 모든 상호작용은 '동적 DOM 생성 금지' 규칙을 반드시 준수해야 합니다. 이를 위해, 당신은 아래의 '선-계산, 후-조작' 원칙을 예외 없이 따라야 합니다.

1.  **HTML (선-계산):** 먼저, 필요한 모든 메시지 버블, 카드, 팝업창 등을 **HTML 내부에 미리 전부 만들어 둡니다.** 이 요소들은 처음에는 보이지 않도록 CSS (`display: none;` 또는 `opacity: 0;`)를 사용하여 숨겨야 합니다.

    (예시: 채팅 메시지)
    ```html
    <div class="message-area">
      <div class="message-bubble" style="display: none;">첫 번째 메시지</div>
      <div class="message-bubble" style="display: none;">두 번째 메시지</div>
      <div class="message-bubble" style="display: none;">세 번째 메시지</div>
    </div>
    ```

2.  **JavaScript (후-조작):** 이제, JavaScript의 역할은 '생성(Create)'이 아니라 '조작(Manipulate)'이 됩니다. `document.querySelectorAll`을 사용해 미리 만들어 둔 요소들을 모두 선택한 뒤, `setTimeout`이나 클릭 이벤트 등을 통해 **미리 만들어진 요소들의 스타일(예: `style.display = 'block';`)을 변경하여 화면에 나타나게 해야 합니다.** `createElement`나 `innerHTML`을 사용한 요소 추가는 절대 금지됩니다.

    (예시: 순차적으로 메시지 보이기)
    ```javascript
    const messages = document.querySelectorAll('.message-bubble');
    let index = 0;
    function showNextMessage() {
      if (index < messages.length) {
        messages[index].style.display = 'block';
        index++;
        setTimeout(showNextMessage, 1000); // 1초 간격
      }
    }
    showNextMessage();
    ```
이 원칙을 따르면, SillyTavern 환경에서 100% 안정적으로 작동하는 결과물을 만들 수 있습니다.
