   - **당신의 임무:** 위 '주어진 핵심 주제'를 **'변칙 개체'나 '이상 현상'을 지칭하는 보고서 형식의 제목**으로 변환해야 합니다.

#### 반응형 레이아웃 추가 지침

**모바일 우선 단일 열 구조:**
모든 콘텐츠는 기본적으로 **화면 전체 너비를 사용하는 단일 열(Single Column) 구조**로 설계되어야 합니다. 이는 모바일 환경에서의 가독성을 최우선으로 보장하기 위함입니다. 정보상자(infobox)와 같은 요소도 본문 콘텐츠의 일부처럼 세로로 순서대로 배치되어야 합니다.

**넓은 화면을 위한 2단 구조:**
데스크톱과 같이 넓은 화면을 위해, **CSS `@media` 쿼리를 사용하여 화면 너비가 `768px` 이상일 때만 정보상자가 우측에 배치되는 2단 구조를 적용할 수 있습니다**. 아래 예시 코드를 정확히 참조하여 이 반응형 로직을 구현해야 합니다.

```css
/* 정보상자(infobox) 기본 스타일 (모바일): 일반 블록 요소 */
.infobox {
  width: auto;
  float: none;
  margin: 0 0 1em 0; /* 아래쪽에만 여백 */
}

/* 넓은 화면(768px 이상)에서만 적용되는 스타일 */
@media (min-width: 768px) {
  /* 정보상자를 우측에 배치 (2단 구조) */
  .infobox {
    width: 300px;
    float: right;
    margin: 0 0 1em 1.5em; /* 왼쪽과 아래쪽에 여백을 주어 본문과 분리 */
  }
}
```

**스타일별 디자인 적용:**
위 반응형 구조를 기본으로 하되, 위키 스타일의 고유한 색상, 폰트, 분위기를 디자인에 반영해야 합니다.

#### STEP 4: 공통 UI 기능 - 라이트/다크 모드 전환

**당신은 아래의 명세서를 단 하나도 빠짐없이 정확하게 따라 라이트/다크 모드 전환 기능을 구현해야 합니다.**

1. **HTML 구조:**
   화면의 일관된 위치(예: 우측 상단 헤더)에 테마 전환을 위한 버튼을 배치합니다. 이 버튼은 아이콘(예: `🌙`/`☀️`) 형태여야 하며, 명확한 ID를 가져야 합니다.
   **(예시):** `<button id="theme-toggle-btn">🌙</button>`

2. **CSS 구현 (매우 중요):**
   - **CSS 변수 정의:** 스타일시트 최상단 `:root` 선택자 안에 라이트 모드를 기본으로 하는 색상 변수들을 모두 정의해야 합니다.
     ```css
     :root {
       --background-color: #ffffff;
       --text-color: #222222;
       --link-color: #0645ad;
       --border-color: #a2a9b1;
       /* ...기타 필요한 모든 색상 변수 */
     }
     ```
   - **다크 모드 재정의:** `body` 태그에 특정 클래스(예: `.dark-mode`)가 적용되었을 때를 위한 색상 변수들을 재정의합니다.
     ```css
     body.dark-mode {
       --background-color: #202124;
       --text-color: #e8eaed;
       --link-color: #8ab4f8;
       --border-color: #5f6368;
       /* ...기타 필요한 모든 색상 변수 */
     }
     ```
   - **변수 사용:** 문서의 모든 색상 관련 속성(`color`, `background-color`, `border-color` 등)은 **반드시 위에서 정의한 `var()` 함수를 사용해 적용해야 합니다.** 직접 색상 코드(예: `#ffffff`)를 사용하는 것은 절대 금지됩니다.
     ```css
     body {
       background-color: var(--background-color);
       color: var(--text-color);
     }
     a {
       color: var(--link-color);
     }
     ```

3. **JavaScript 구현:**
   스크립트는 위에서 정의한 HTML 버튼(`theme-toggle-btn`)을 클릭했을 때, `body` 태그에 `.dark-mode` 클래스를 추가하거나 제거하는 **단 하나의 기능만** 수행해야 합니다.
   ```javascript
   const themeToggleButton = document.getElementById('theme-toggle-btn');
   themeToggleButton.addEventListener('click', () => {
     document.body.classList.toggle('dark-mode');
     // 아이콘 모양 변경 로직 (선택사항이지만 권장)
     if (document.body.classList.contains('dark-mode')) {
       themeToggleButton.textContent = '☀️';
     } else {
       themeToggleButton.textContent = '🌙';
     }
   });
   ```
