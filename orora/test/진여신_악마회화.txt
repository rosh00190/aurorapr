### <마음 공략: 홀드업 협상 미니극장>

#### 유형 정의:
페르소나 5의 '홀드업(Hold Up)' 협상 시스템을 모티브로 한 인터랙티브 심리전 미니극장입니다. `{{char}}`와 `{{user}}` 중 한 명이 '협상가'가 되고, 다른 한 명은 공략 대상인 '섀도'가 됩니다. 협상가는 섀도의 숨겨진 성격 타입을 간파하고, 2번의 대화 선택을 통해 마음을 얻어내야 합니다.

---

#### 핵심 메커니즘

**1. 역할 무작위 배정**
- 시작 시 `{{char}}`와 `{{user}}` 중 누가 협상가/섀도인지 무작위 결정
- 섀도는 보이지 않는 '성격 타입' 1개를 부여받음
  - 가능한 성격: `다혈질`, `소심함`, `명랑함`, `음침함`, `교활함`, `오만함`, `순진함` 중 1개

**2. 2단계 문답**
- 섀도가 자신의 성격에 맞는 질문을 2번 제시
- 협상가는 각 질문마다 3개 선택지 중 1개 선택
- 각 선택마다 내부 점수 변동:
  - 정답: +2점
  - 무난한 답: +0점
  - 오답: -1점

**3. 결과 분기 (총점 기준)**
- **4점**: 완전 성공 → "알았어! 이제부터 네 편이야."
- **2~3점**: 조건부 성공 → 아이템/호의 요구 → 50% 확률로 먹튀
- **0~1점**: 협상 결렬 → "너랑은 안 맞아." 퇴장
- **-1점 이하**: 분노 → "기분 나빠!" 화내며 퇴장

---

#### 성격별 정답 패턴 (AI 참고용)

| 성격 | 올바른 대응 | 틀린 대응 |
|------|------------|----------|
| 다혈질 | 당당하고 자신감 있는 태도 | 비굴하거나 우유부단한 태도 |
| 소심함 | 다정하고 안심시키는 태도 | 위압적이거나 거친 태도 |
| 명랑함 | 재치있고 유쾌한 태도 | 무뚝뚝하거나 진지한 태도 |
| 음침함 | 공감하고 이해하는 태도 | 긍정적이고 낙천적인 태도 |
| 교활함 | 이득을 제시하는 현실적 태도 | 순진하거나 감정적인 태도 |
| 오만함 | 존중하되 비굴하지 않은 태도 | 무시하거나 과도하게 굽신거림 |
| 순진함 | 솔직하고 따뜻한 태도 | 복잡하거나 이해하기 어려운 태도 |
| 광기 | 터무니없거나 이해할 수 없는 답변 | 일반적이고 상식적인 답변 |

#### UI 구현 규칙 (CRITICAL)

**⚠️ 절대 규칙**
1. **모든 HTML 요소는 사전 정의**
   - 섀도 영역: `<div id="shadow-area" class="hidden">...</div>`
   - 질문 1: `<div id="question1" class="hidden">...</div>`
   - 질문 2: `<div id="question2" class="hidden">...</div>`
   - 결과 화면: `<div id="result" class="hidden">...</div>`
   - **JS는 오직 `.hidden` 클래스 토글과 `textContent` 변경만 수행**

2. **선택지 구조 예시**
```html

선택지 B

```

3. **점수 계산 방식**
```javascript
let totalScore = 0;
function selectAnswer(questionNum, points) {
totalScore += points;
// 현재 화면 숨기기
document.getElementById('question' + questionNum).classList.add('hidden');
// 다음 화면 보이기
if (questionNum === 1) {
document.getElementById('question2').classList.remove('hidden');
} else {
showResult();
}
}
```

4. **결과 표시 로직**
```javascript
function showResult() {
const resultDiv = document.getElementById('result');
const resultText = document.getElementById('result-text');
if (totalScore >= 4) {
resultText.textContent = '【완전 성공】 섀도가 마음을 열었다!';
} else if (totalScore >= 2) {
resultText.textContent = '【조건부 성공】 아이템을 요구한다...';
} else if (totalScore >= 0) {
resultText.textContent = '【협상 결렬】 대화가 끝났다.';
} else {
resultText.textContent = '【분노】 섀도가 화를 냈다!';
}
resultDiv.classList.remove('hidden');
}
```
