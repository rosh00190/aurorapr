【살아 숨 쉬는 커뮤니티 시뮬레이터 v2.0】

#### 유형 정의:

이 미니극장은 단순한 UI 모방을 넘어, 현재 `{{char}}`와 `{{user}}`가 속한 세계의 커뮤니티를 살아 숨 쉬는 것처럼 시뮬레이션하는 고도의 인터랙티브 콘텐츠입니다. 당신은 먼저 현재의 대화 맥락과 세계관을 분석하여 가장 적합한 커뮤니티 테마를 동적으로 생성합니다. 그 후, 다양한 형식과 분량의 게시물 목록을 구현하고, 사용자가 특정 게시물을 클릭하면 상세 보기 화면으로 전환되어 깊이 있는 내용과 대댓글까지 확인할 수 있는, 실제 커뮤니티와 같은 다층적인 탐색 경험을 제공합니다.
모든 컨텐츠는 반드시 한국어로 작성해야합니다.


#### STEP 1: 동적 테마 및 분위기 설정


당신의 첫 번째 임무는 코드 생성 전, 아래 지침에 따라 이 미니극장의 핵심 테마를 결정하는 것입니다.

1.  맥락 분석: `{{char}}`와 `{{user}}`의 현재 관계, 직업, 대화 장소, 그리고 시대적/장르적 배경(판타지, SF, 현대 등)을 종합적으로 분석합니다.
2.  테마 창조: 분석 결과를 바탕으로, 해당 세계관에 가장 어울리는 커뮤니티의 형태를 구체적으로 정의합니다.
    *   (예시)
        *   중세 판타지: `왕궁 마법사들의 비밀 연구 포럼`
        *   사이버펑크 미래: `불법 개조 부품을 거래하는 뒷골목 네트워크`
        *   현대 대학 캠퍼스: `익명 대나무숲 애플리케이션`
        *   잔잔한 일상: `단골들만 아는 동네 카페의 온라인 게시판`
3.  디자인 및 언어 설정: 창조한 테마에 맞춰 UI 디자인 콘셉트(색상, 폰트, 레이아웃)와 커뮤니티 구성원들의 말투, 은어 등을 결정합니다.


#### STEP 2: 게시물 콘텐츠 생성 가이드

*   생성 수량: 최소 3개에서 5개 사이의 게시물을 생성합니다.
*   댓글/대댓글 수량:
    *   각 게시물에는 0개에서 7개 사이의 댓글을 무작위 수량으로 생성합니다.
    *   댓글 중 1~2개에는 1개에서 3개 사이의 대댓글을 추가하여 깊이감을 더합니다.
*   주제 선정: 아래 `<게시물 생성 주제 가이드>`를 참고하여 다양한 주제의 게시물을 작성합니다.
*   분량 및 형식 다양화 (매우 중요): 생성되는 게시물들은 반드시 아래 형식들을 골고루 포함해야 합니다.
    1.  단문형 (1~2개): 1~3줄의 짧은 잡담이나 질문. (예: "오늘 `{{char}}` 표정 안 좋던데 뭔 일 있음?")
    2.  장문형 (1~2개): 5~10줄 이상의 긴 분석 글, 상세한 목격담, 혹은 진지한 토론 글.
    3.  이미지 첨부형 (1개): 글 내용은 짧지만, 상황을 암시하는 이미지가 첨부된 게시물.
        *   이미지 구현: 실제 이미지는 `https://image.pollinations.ai/prompt/{...}` API를 사용하여 생성합니다. 인물 묘사는 절대 금지 규칙에 따라, `어두운 골목길 풍경`, `깨진 찻잔`, `밤하늘의 인공위성` 등 상징적인 사물이나 배경 이미지를 생성하도록 지시합니다. 이미지 아래에는 `[이미지 설명: 어두운 카페 구석에 놓인 두 개의 커피잔]`과 같은 캡션을 추가합니다.

#### <게시물 생성 주제 가이드>

*   기본 지침: 게시물의 내용은 항상 `{{char}}`와 `{{user}}`를 중심으로 하되, 직접적으로 언급하기보다는 은유나 별명, 암시를 사용하여 제3자의 시선임을 명확히 합니다.

*   주제 카테고리 (이 중 2~3개를 조합하여 사용):
    1.  목격담/소문: `{{char}}`와 `{{user}}`가 함께 있는 것을 본 후기나 그들에 대한 추측성 가십.
    2.  정보 질문: 둘의 관계나 정체에 대해 궁금해하는 질문 글.
    3.  사건 관련 토론: 최근 둘 사이에 있었던 특정 사건에 대한 커뮤니티의 반응이나 토론.
    4.  일상 잡담: 커뮤니티의 성격에 맞는, 둘과 직접적인 관련은 없지만 세계관의 생생함을 더해주는 잡담 글.
    5.  내부자 경고/조언: 익명을 빌려 `{{user}}`나 `{{char}}`에게 무언가를 경고하거나 조언하는 듯한 뉘앙스의 글.

#### STEP 3: UI 및 상호작용 명세

*   모바일 최적화: 모든 UI 요소는 모바일 화면에 최적화된 세로형 레이아웃을 기본으로 합니다.
*   화면 전환 로직 (핵심 상호작용):
    1.  초기 화면 (게시물 목록):
        *   처음에는 각 게시물의 '제목', '작성자', '작성 시간', '추천 수', '댓글 수'만 리스트 형태로 간결하게 보여줍니다.
        *   장문형 게시물은 본문 일부(약 1줄)만 미리보기로 보여줍니다.
        *   이미지 첨부형 게시물은 작은 썸네일 아이콘(🖼️)을 제목 옆에 표시합니다.
    2.  상세 보기 화면:
        *   사용자가 목록에서 특정 게시물 제목을 클릭하면, 목록 화면은 사라지고 해당 게시물의 상세 보기 화면으로 전환됩니다.
        *   이 화면에는 게시물의 전체 본문, 첨부 이미지(존재 시), 그리고 댓글과 대댓글이 모두 표시됩니다.
        *   화면 상단에는 `[← 뒤로가기]` 버튼이 있어 언제든 게시물 목록으로 돌아갈 수 있습니다.
*   실시간 상호작용 구현:
    1.  추천/비추천 토글: 목록과 상세 보기 화면 모두에서 작동해야 합니다.
    2.  댓글과 대댓글:
        *   상세 보기 화면에서 댓글 목록이 나타납니다.
        *   각 댓글 옆의 `답글 달기` 버튼을 누르면 해당 댓글 아래에 들여쓰기 된 대댓글 입력창이 나타납니다.
    3.  답글 입력 시뮬레이션:
        *   `답글 달기` 버튼 클릭 시, 작은 텍스트 입력창과 `전송` 버튼이 나타납니다.
        *   사용자가 실제로 텍스트를 입력하고 `전송`을 누르면, "메시지가 성공적으로 등록되었습니다." 와 같은 피드백을 잠시 보여준 뒤 입력창을 사라지게 하여 실제 작성 경험을 시뮬레이션합니다.
    4.  게시물 신고 기능:
        *   게시물 우측 상단의 '더보기(...)' 아이콘을 클릭하면 `신고하기` 옵션이 나타납니다.
        *   클릭 시, 테마에 맞는 신고 사유(예: `스포일러`, `기밀 누설`, `분란 조장`)를 선택할 수 있는 팝업창을 띄우고, 확인 시 접수 완료 피드백을 보여줍니다.
